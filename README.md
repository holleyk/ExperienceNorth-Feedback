# Experience North feedback

Report a website problem, suggest an improvement, or request a correction to visitor information.

Use **Issues → New issue** to choose a form. A GitHub account is required. Reports and replies are public: do not include personal contact details, passwords, private correspondence or other sensitive information.

For private questions, email [contact@experiencenorth.ca](mailto:contact@experiencenorth.ca).

This repository contains feedback only. It does not contain the application code. Submitting feedback does not guarantee a response or a particular change. Visitor-information corrections are reviewed before publication.
